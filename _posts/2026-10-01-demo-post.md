## Mathematics {#mathematics}

## Code with copy and syntax highlighting {#code}

Inline code works for short commands such as <code>python fit_model.py</code>. The example below has a local copy button and lightweight highlighting for the displayed Python snippet.

    # Mean squared error

    return (residuals ** 2).mean()</code></pre>
